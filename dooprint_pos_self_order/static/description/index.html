Dooprint for POS Self Order

Kiosk and mobile self orders printed on the printers of a dooprint device.

What it does

Self Order lets a customer order from a kiosk or from their own phone. This module is the bridge that takes those orders to the printers of a dooprint device: the kiosk receipt and the order ticket for the kitchen or the bar.

It installs itself as soon as Dooprint for POS and Self Order are both present, and it uses the printers already configured there. There is nothing new to set up.

The phone is not on the printer network

A kiosk sits in the shop, so it can print by whichever delivery its printer uses. A customer's phone is a different story: it is on mobile data or on the guest network, and it will never reach the printer directly.

So orders placed from a phone always travel through Odoo, which queues them for the device. The public route only ever prints an order that belongs to that point of sale, and the order is verified before anything is queued.

Getting started

  1. Install Dooprint for POS and choose its printers on the point of sale.
  2. Enable Self Order on the point of sale.
  3. This module installs itself and the self orders print on those same printers.

Requires Odoo 19, the Point of Sale application and Self Order.
